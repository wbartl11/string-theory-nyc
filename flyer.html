How to print

File → Print (or ⌘P) → Paper size: US Letter → Margins: None → turn ON "Background graphics" so the green prints. Cut along the dashed lines between the tear-off tabs before posting. The QR code opens stringtheorynyc.com and works offline (no image to load).
